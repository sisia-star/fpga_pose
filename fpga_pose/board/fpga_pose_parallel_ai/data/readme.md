# 预置动作数据集

`archive.zip` 是用户提供文件的原样副本，包含五份 CSV。`landmarks.csv` 和 `labels.csv` 用于模型生成；其余文件保留在原档案中，本版不将预计算角度直接当作实时特征。

原档案有 1,372 条带标签姿态，包含五运动、十个 up/down 阶段。去掉相同标签的完全重复坐标后剩 1,371 条。未提供原视频编号、人物编号、帧时间或可见性，因此样本拆分验证不等于独立视频验证，不能据此声称来自447段序列的信息已核实。

坐标已移到髋中心附近，二维人体尺度约为100。本版按这一数值协议接入，参考特征为CSV xyz除100；实时特征从图像坐标恢复xy/z尺度，再使用相同髋中心和二维身体尺度归一化。该兼容方式依据文件数值和官方参考流程，原提取脚本来源尚未确认，最终须在真实摄像头上核对。

源文件由用户提供，未填写可验证的源下载页或提取脚本。该文件不包含运动规范程度标签。
